# Network Security

This section contains network-based security investigations focused on traffic analysis and intrusion detection.

---

## Overview

This section focuses on network security monitoring, traffic analysis, intrusion detection and network-based threat investigation.

The write-ups document practical analysis of network traffic using packet capture and intrusion detection technologies. The focus is on identifying suspicious activity, analysing network protocols, investigating captured traffic and understanding how network monitoring capabilities support SOC operations.
